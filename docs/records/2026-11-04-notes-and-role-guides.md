# 备注、账号台账与角色指南

- 备注作者可删除自己的备注，网页管理员可删除任意备注；写入在事务中检查作者与机器可见性，保留审计。
- 账号台账按机器分组，保留人员归属、状态、sudo 开关及原有行操作，申请者只看自己的账号。
- 图文与 PDF 由当前会话角色选择，匿名不可访问；查询参数不能覆盖角色，退出后清除页面内容。
- 通用图文与内部分发资料使用不同目录，Web UI 只读取 `web-tutorials`；缺少文件时回退随包的通用文字指南。
- 截图使用独立演示数据和模拟传输，不把任何真实部署或接入资料放入源码或公开附件。
- 相关备注与页面回归检查点、后续管理改密见[管理改密记录](2026-11-04-management-passwords.md)和[教程通用化记录](2026-11-04-generic-guides-and-sticky-people.md)。
