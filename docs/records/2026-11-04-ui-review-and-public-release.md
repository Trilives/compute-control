# 界面复查、宽松限频及首次公开发布

## 授权与决策

人类确定目标和验收标准，Agent 主导实现。用户授权放宽公司局域网限频、全面审查按钮位置和功能入口、创建公开 Git 仓库并发布 Release；正式部署在用户提供主机信息后另行执行。后续补充英文姓名登录忽略大小写，纳入本批版本。

- 登录失败从每种角色/来源 IP 的 10 次/600 秒调整为 100 次/60 秒，成功登录不占失败次数；管理员与申请者互不消耗限额。
- 刷新从 30 秒拒绝重复请求改为 5 秒内及排队中的重复请求合并，返回已排队，保留原请求时间，避免频繁点击报错或不断推迟采集。小时后台采集及同机串行规则保持。
- 英文姓名及中英文混合姓名按 ASCII 大小写无关匹配，保留登记显示写法；新增、改名及删除后恢复采用同一规则。旧大小写冲突拒绝歧义登录，管理员改名处理，不自动合并人员、账号或数据；现有名单只读检查未发现冲突。
- 不增加模块、依赖、启动配置或新运行模式，现有职责和依赖方向保持；完整规则及接口行为已同步[架构](../../ARCHITECTURE.md)及两份公开指南。

## 界面审查与修正

- 常用入口优先：当前状态、账号台账、权限申请、后台任务；管理员再展示姓名额度、公告、联系名单、归档和操作记录，申请者仅展示其可用页面。
- 每页都有手动“更新显示”，不会自动轮询；更新后保留当前页。联系方式和旧联系说明集中在管理员名单，移除姓名额度页的分散入口。
- 机器查看与管理按钮分组，重启位于管理组最后；账号行把回收置于常规管理操作后。管理员入口仍在姓名窗口右上角，申请者顶栏联系按钮仍紧跟申请管理权限。
- 编辑机器弹窗正确显示“更新机器与凭据”和“检查并保存”；添加入口继续显示添加文案。顶栏和页面操作栏可换行，维持三列机器卡片对齐与窄屏适配。
- 检查完整指南、工具说明、备注、账号权限及历史图入口，固定关闭栏和告警层级；修正管理员指南中残留的旧联系方式位置说明。
