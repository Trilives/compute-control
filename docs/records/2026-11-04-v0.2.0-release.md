# v0.2.0 发布验证

## 使用者可见变更

- 机器卡片将申请开关、机器账号与 sudo 权限、连接凭据、管理账号改密和重启集中到“管理机器”，原表单与危险操作确认继续使用。姓名表格操作栏在长列表中保持可见。
- 账号台账按机器展示最后活跃时间：该机该账号最近一次可观测成功登录；未知显示“暂无记录”，不等同从未使用。时间持久保存，原始登录明细过期不清除最后观测值；旧库从已有记录回填。
- 新配置 `https_enabled` 明确选择 HTTP/HTTPS，示例选择 HTTP；HTTPS 需要证书和私钥。省略此项的旧安装兼容原传输规则，不自动切换既有环境；旧开发 TLS 启动也使用 Secure Cookie。
- Web 管理密码、接入时录入的机器管理账号密码和普通账号密码分别处理。管理改密保留加密候选、验证新连接后同步，结果不明只核查、不自动重放。
- 备注作者可删除自己的备注，网页管理员可删任意备注；分角色图文文件和 PDF 下载受真实会话保护，没有自备文件时回退内置文字指南。

## 公共发布边界

- README、配置、部署及操作文档面向独立安装者，移除个人工作目录、现场机器称呼和网络拓扑；示例路径与配置均可由部署者调整。
- Release 仅提供应用 wheel、源码发行包及 SHA-256 校验文件。实际数据库、密码、主密钥、证书/私钥、SSH 主机记录、现场网络名/密码/初始节点及受限教程不进入提交、构建包或附件。
- 本地检查使用已知部署秘密、密文、密码哈希、主密钥和主机标识逐一匹配，同时检查私钥/令牌标记；扫描工作树、所有尚未公开的提交内容、wheel 和 sdist，输出仅含通过状态或问题文件名。
- 完整现场资料只保存在被忽略且受限的本地目录，公开记录保留可复用的方法、代码证据和验证边界。
