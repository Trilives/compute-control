# v0.2.1：通用图文与分发资料隔离

- Web UI 的 HTML/PDF 与元数据只读取 `<runtime_dir>/web-tutorials`，不再读取旧 `tutorials` 或其他线下分发目录。
- Web 目录或文件为软链接时拒绝提供；缺少有效通用图文则回退随发行包的通用文字指南，不猜测其他目录。
- 角色仍由实际登录会话决定，查询参数不能切换角色或目录；匿名访问、下载缓存与脚本限制保持原行为。
- 用户自备资料应分开维护：Web UI 放通用操作，线下分发可由维护人按授权附带其连接及运维资料，后者不属于源码或 Release 附件。
- 公开文档移除特定网络产品及现场分发的描述。实际秘密、部署资料与受限图文继续只由部署者私下保管。
- 新增回归构造同名线下资料，确认不会被当作 Web 图文读取；分别验证文档软链接及整个目录软链接被拒绝。完整 200 项测试通过，旧资料回退 RED 检查点 `ce2c603`、软链接 RED `9eebb81`。
- 迁移时将通用 HTML/PDF 单独安装到 `web-tutorials`；不要将原含现场资料的文件直接复制过去。旧目录未迁移时，Web UI 使用文字回退。
- 包版本、示例与公开说明同步为 0.2.1。该版本不修改账号、机器连接凭据或后台任务格式。

检查只报告是否命中私密值和问题文件路径，不在公共结果、日志或示例中复写任何实际连接参数。
