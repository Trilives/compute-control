# 受控网络入口兼容性记录

- Web 可按配置监听实际需要的地址，防火墙由部署者按来源、网卡及目标端口限制；不预设组网软件、虚拟网段或机器数量。
- HTTPS 证书必须覆盖实际访问名称或地址；网络隧道和 HTTPS 的传输保护各自独立，不能替代访问权限控制。
- 网络变更前保存配置、TLS 材料及防火墙规则，只调整本服务的精确规则，不覆盖既有 SSH 或其他服务。
- 服务本机健康检查仅证明监听可用；跨网络访问必须从相应网络的独立客户端验证，不能用本机检查代替。
- Web 与 worker 独立运行，可在无需变更任务执行器时单独更新 Web；重启和跨节点测试范围应如实记录。
- 具体地址、接口、账号、证书和现场验证原始数据由部署者私下保管，不属于公开发行内容。
- 当前部署方法及传输选项见[部署文档](../DEPLOYMENT.md)；本记录不包含任何实际网络接入参数。
