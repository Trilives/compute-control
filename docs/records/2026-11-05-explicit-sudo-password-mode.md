# 管理账号默认同步 sudo 密码

- 录入机器默认只填写管理账号登录密码，同时作为 sudo 连接凭据；显式勾选“使用独立 sudo 密码”才展示第二项，免密可留空。
- 录入及更新凭据在连接检查前统一处理模式，成功核验机器身份后保存加密凭据与明确选择；失败不覆盖原设置。
- 管理改密遵循保存的模式：默认同步 SSH/sudo，独立模式保留 sudo，即使两项当前相同也不自行合并。
- 旧数据缺少标记时保留原认证方式：两项相同视为同步，不同视为独立；只读展示不改库，成功更新或改密后保存明确模式。
- 管理员可见模式，申请者不获取该配置或凭据；表单不预填秘密，取消独立模式或关闭表单清空输入。
- 保存成功后先更新机器状态再关闭表单，避免紧接着打开改密窗口时显示旧模式。
- 通用管理员指南补充规则和录入截图，改密配图更新；图片均来自隔离数据库与 FakeRemote，不使用真实连接或用户数据。

- 公开文件、可达历史及构建包通过已知私密材料检查；内部教程、真实拓扑和凭据不进入公开提交或发行包。
- 已部署到独立程序目录，切换前备份状态与密钥；仅重启 Web，worker 保持运行，原机器凭据及网页密码哈希未改动。
