# 账号分配、暂停、回收与恢复

- 关闭机器申请后，申请者不能新建账号，管理员可在“管理机器 → 为人员分配账号”为启用人员代建；仍校验创建能力、重名、人员总额度和维护状态。服务端记录代分配来源，worker 不误取消这类任务。
- “暂停使用 / 启用账号”仅管理员可操作：保留账号、密码、主目录及额度，阻止新的登录；活动进程、调度项及身份保护仍适用，不自动结束计算工作。
- 回收在完整归档校验后自动删除账号和原 home，完成记录移出账号台账并进入管理员回收站。旧的未清理记录保留手动核查入口。
- 恢复先预留额度，校验账号、UID、原路径和所有权。原 home 已清理时校验归档，在受保护临时目录解包，核对内容及元数据，无覆盖地移回，再重建同名同 UID 账号并恢复回收前密码。归档继续保留，sudo 权限需单独核查。
- 删除姓名先展示所有机器账号的处理计划。确认提交时在同一事务中核对计划摘要，撤销会话并提交批量回收；未执行的创建任务安全取消，已有回收不重复排队，其他未完成或不确定操作要求先核查。
- 失败保留账号映射、原任务、归档及审计；操作不明时保留额度，不盲目重放。已被另一个账号或目录占用的目标拒绝覆盖。
- Web 两份通用 Markdown 指南已同步；运行配置、内部文档、网络资料及密码不进入源码或发行包。
