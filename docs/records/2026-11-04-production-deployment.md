# 独立控制服务部署与迁移记录

## 实现与验证边界

- Web 与 worker 使用独立非 root 服务身份、systemd 管理和受限运行目录；低端口绑定能力仅按需要授予 Web，worker 不需要该能力。
- SQLite backup API 用于一致性快照，数据库与匹配主密钥一并受限备份；隔离恢复检查完整性、业务记录和凭据可解密。
- 数据迁移不重放已完成或结果不明的任务；迁移前核对执行中的任务，旧 worker 不与新 worker 同时运行。
- 依赖可按锁文件为目标 Python/平台准备 wheel 并校验摘要后离线安装；包和入口需能被服务身份读取，安装权限与敏感状态权限分开处理。
- 运行身份导入验证、健康检查、登录、CSRF、Cookie 和后台只读采集用于确认安装；真实创建/回收仍须专用测试资源。
- 防火墙只调整本服务所需来源及端口，不清空已有规则；IPv4/IPv6、上游网络和实际跨网络访问分别确认。
- 服务级重启和开机启用检查不等于整机重启验收；网络命名空间测试不等于独立外部实体机器测试。
- 具体机器、人员、账号、数据数量、地址和凭据不属于公开交接记录，完整现场原始资料受限保存在部署者环境。

HTTP / HTTPS 均可选，独立 unit、配置、备份恢复及升级步骤见[部署文档](../DEPLOYMENT.md)。每个新环境需要按自身发行版与认证策略验收，不能直接沿用其他安装的现场结论。
