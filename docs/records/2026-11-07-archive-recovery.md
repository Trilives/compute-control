# 按归档记录恢复与旧密码兼容

- 将完成回收记录的恢复入口合并到“归档记录”，移除单独的回收站导航。每条归档保留恢复按钮，归档已删除、账号已恢复或有未完成任务时禁用重复恢复。
- 选择的归档 ID 在事务中绑定账号、机器、路径、大小和摘要，远端校验所选文件与身份元数据；不以最新归档替代用户选中的记录，不覆盖现有目录或账号。
- 有留存密码时可直接沿用，也可输入新密码；没有留存密码的历史记录必须输入恢复后的密码。缺少旧密码哈希的归档也可在身份及数据校验通过后恢复，密码仅从标准输入传递给账号工具。
- 候选密码加密保存在任务中，接口及任务列表不返回密文或明文；对话框关闭后清空密码。通过远端完成回执核对中断的恢复，成功核对后同步密码留存，不盲目重放。
- 两份 Web 通用 Markdown 指南同步更新。兼容已有台账显示清理记录，归档列表仍展示可恢复的完整记录。
- 排查长时间回收时只读核对了远端状态、进程 CPU/I/O 与归档大小；任务持续执行并自行成功完成，账号及原目录清理和额度释放均已核实，没有中止或重复提交。

## 验证与部署

- RED：新增测试先复现缺少逐条归档恢复、未标识历史密码状态、不能从缺少密码哈希的旧记录恢复，以及忽略所选归档摘要等情况。
- GREEN：完整 250 项测试通过，总语句覆盖率 81%；Ruff、格式、JavaScript 语法、差异、文件长度及发行包隐私检查通过。
- 回归包含真实 tar 解包和文件保留、旧密码输入、所选历史归档、摘要拒绝、管理员权限、断线结果核对、密码清除及 Chromium 页面流程。
- 远端操作仍为单次 SSH 传输的自包含脚本。为所选归档验证及旧记录恢复将 `remote.py` 长度上限由 1250 调整为 1300 行；归档业务和浏览器交互分别拆为独立模块。
- 服务器配置与密码以实际部署保存的资料为准；部署使用版本目录、数据库和主密钥备份、健康检查及回滚，验收不提交真实账号恢复任务。实际部署及桌面/手机页面核对已通过，三台机器当前保存的 SSH/sudo 凭据和系统设置保持有效。
