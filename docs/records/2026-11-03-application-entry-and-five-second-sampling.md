# 2026-11-03 申请入口、5 秒折线采样及普通密码调整

- 用户要求：补齐申请者的申请按钮；每 5 秒探测，保留折线并为每次采样显示圆点；同机重名拒绝；个人普通账号密码至少 3 字符，不要求复杂度。
- 申请入口：概览顶部、机器卡片和账号台账均可进入申请；卡片预选机器。未开放、同机已有账号或额度已满时明确提示，不改变后端权限/额度约束。
- 采样：配置和浏览器心跳/刷新均改为 5 秒；调度按上次任务开始时间安排下一次，避免把探测耗时反复叠加到周期。仍仅可见且已进入模式的页面续租，异常断开兜底租约保留 25 秒。
- 图表：折线与每个有效点同时存在，点悬停显示采样时间和值；按实际采集时间去重，未知值不画成零，超过间隔的空档不补线。最多 120 个真实点，保持 10 分钟窗口。
- 重名：最新机器用户名清单（包含系统及历史账号）和登记表都先检查，已知同机重名在预占额度前拒绝；远端真正创建前仍复查，不覆盖用户或密码。并发由原有事务/唯一约束兜底。
- 普通密码：申请、原任务重输、worker 内存通道和远端脚本均接受 3–256 字符；不强制字符组合，协议限制的换行/NUL/冒号继续排除。控制台管理员密码规则不属于此次普通账号调整范围。
- 修复：按钮回调的同步异常也进入统一提示，避免无可申请机器时页面没有反馈。
- 自动化：全量 82 项通过，新增 3 位普通密码、重名不占额度、圆点去重，以及申请者从概览/卡片实际提交的浏览器路径。后端额度/归属原有验证保留。
- 实际生效：已正常重载 Web 和 worker；实际 HTTP 校验确认普通账号 3 位密码不再被长度拦截、2 位按约定拒绝，申请及重输表单均为 3 位，运行采样配置为 5 秒。使用受保护用户名触发拒绝验证，未新建任务或修改远端账号。
