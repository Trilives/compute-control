# 分角色图文指南与普通 HTTP 兼容

- 管理员和申请者分别提供上手流程及细节说明；管理员版本按角色限制，登录凭据单独保管。
- 图文文件由部署者自行安装，使用自包含 HTML 及 PDF；网络参数、现场机器信息和实际凭据不进入公共发行包。
- 通用文字指南随包提供，缺少自备图文文件时自动回退；角色选择由实际会话决定，查询参数不覆盖权限。
- 演示截图在独立数据库和 FakeRemote 中生成，未使用真实用户数据，也未执行真实账号生命周期操作。
- 普通 HTTP 中缺少 `crypto.randomUUID` 时，旧申请表单打不开。新增 Chromium 回归后改用 `crypto.getRandomValues` 生成 128 位幂等标识。
- RED 检查点 `8c30a0e`，GREEN 检查点 `d4c9f5e`；HTTP、浏览器与界面回归 16 项通过。
