# v0.2.2：Web UI 内嵌 Markdown 图文

- Web UI 的角色指南固定来自安装包内的管理员/申请者 Markdown，配图使用独立演示数据生成的本地 PNG，并随仓库与发行包提供。
- 浏览器直接在指南弹窗内渲染，不使用 iframe，也不提供通用 PDF 下载；移除旧运行目录图文覆盖及文档/下载路由。
- 标题、列表、表格、代码、粗体、行内代码、链接和演示图片使用 DOM 安全渲染；原始 HTML 不执行，图片仅接受指定的本地静态资源引用，不自动加载外站或私密路径。
- 角色由实际登录会话选择，路径和角色查询参数不能覆盖；任何运行目录中的 Markdown/HTML/PDF 均不作为网页指南来源。
- 内部分发 PDF 与通用 Markdown 分开维护；含实际入口或维护资料的文件不进入公开提交、配图或发行附件。
- 新测试覆盖角色选择、运行目录资料忽略、无 iframe/下载入口、图片加载、桌面/手机布局、退出清理及恶意图片/HTML 不执行。
- 图片来源是隔离数据库和 FakeRemote，截图生成过程不使用真实连接或用户数据；发布前核对文件来源和发行包边界。
- 完整 197 项测试通过；Ruff、格式、JavaScript 语法、文档引用与长度登记通过。所有 13 张公开图片逐字节对应新的隔离演示截图，不包含内部 PDF 的页面预览。
