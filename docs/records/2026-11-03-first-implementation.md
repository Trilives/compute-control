## 已实现及依据

- `app.py/models.py/templates/static` 对应现有 Web/API 职责，`security/services/db` 对应认证、业务及数据访问，`ssh/remote` 对应既有远端适配，`worker` 对应任务/采集；启动由 `config/cli` 装配，没有新的业务模块。
- 新增 FastAPI 0.162.0、Uvicorn 0.54.0、Jinja2 3.1.6：分别提供 API、ASGI 服务及模板；Paramiko 4.0.0 用于固定指纹的 SSH；argon2-cffi 25.1.0 用于密码哈希，cryptography 48.0.1 用于机器凭据认证加密。
- pytest 9.2.0、HTTPX 0.28.1、Playwright 1.64.1、Ruff 0.17.3 分别用于测试、API 测试客户端、真实浏览器和代码检查。版本来自 uv 对 PyPI 的解析结果，完整来源及传递依赖在 `uv.lock`；无全局包修改。
- 单 worker 本机文件锁，受限 Unix socket 仅在内存接收新账号密码；无密码的任务等待重新输入。重启与 SSH 断线不重复变更，管理员核对远端证据。
- 并发额度事务预占、每机申请唯一性、幂等提交及机器关闭取消；管理员查看全部台账，申请者由会话确定归属。
- GPU/登录快照以查看租约触发，多会话合并、隐藏页释放、过期停止；仅缓存最后成功快照，错误保留时间和原因。
- 归档验证成功后删除系统账号，释放额度，原 home 待管理员再校验并清理；永久归档删除需清理完成，留下墓碑与审计。

框架用法参考 [FastAPI 模板](https://fastapi.tiangolo.com/advanced/templates/)、[测试文档](https://fastapi.tiangolo.com/tutorial/testing/)、[Paramiko 客户端](https://docs.paramiko.org/en/stable/api/client.html)、[Argon2 官方用法](https://argon2-cffi.readthedocs.io/en/stable/howto.html)。Context7 工具本次不可用，使用官方来源。
