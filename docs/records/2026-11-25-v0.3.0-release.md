# v0.3.0 发布记录

## 版本范围

- 首页“当前状态”的机器卡片显示滚动 15 天的活跃账号数，按系统用户名去重，排除该机器 SSH 管理账号和 root。登录日志仍用于台账的最后活跃时间，机器列表接口兼容原 30 天字段。
- 管理员可在关闭申请的机器上代分配、暂停和启用账号、审阅受阻回收与未接管账号，并从归档记录逐条恢复。管理员和申请者可选择保持登录。
- 项目版本及锁文件更新为 0.3.0。发行附件为 wheel、源码包和 SHA-256 校验文件。

## 验收

- 全量 277 项测试通过，覆盖 15 天与 30 天的接口计数、名称去重、管理账号排除及 Chromium 首页显示。保留已有的 Starlette TestClient 弃用提示。
- Ruff、Python 格式检查及 JavaScript 语法检查通过。浏览器测试文件为 283 行，上限从 280 行调整为 290 行以保留首页统计回归覆盖。
- 发布审批范围为 GitHub 仓库和 Release，目标机生命周期验收及部署见现有[待办](../TODO.md)。
