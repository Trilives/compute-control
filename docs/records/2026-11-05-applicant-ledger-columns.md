# 申请者台账去除重复姓名

- 申请者台账只包含本人账号，移除每行重复的姓名列；首列直接展示用户名。
- 管理员台账保留姓名，便于核对同一机器上不同人员的账号归属。
- 机器分组、sudo 权限、最后活跃时间、创建时间和操作列保持可用。
- 浏览器回归先确认申请者仍出现姓名列而失败，再验证修改后申请者为六列、管理员保留姓名与权限开关。
- 台账与最后活跃时间相关 5 项测试通过；JavaScript 语法、Ruff 及差异检查通过。
- 已同步部署静态脚本并核对静态资源 HTTP 响应的哈希；部署前保存备份，Web 和 worker 进程均未重启。
- 本次仅调整表格展示，未变更账号归属、服务端访问规则或凭据。
