# 2026-11-03 监控折线、10 秒探测与明暗主题

- 用户要求：CPU、GPU 和显存等占用使用折线图，每 10 秒更新，只在打开网页时持续探测；增加明暗切换，默认白天。
- 范围：沿用现有监控、页面及 SSH 职责；`static/charts.js` 仅封装本页采样缓存和 SVG 渲染，不引入新服务、依赖或 GPU 调度职责。
- 采样：主机/GPU 默认 10 秒；页面可见并进入具体模式后，每 10 秒续期一次 25 秒租约。隐藏/正常关闭主动释放，异常断开等剩余租约到期后停止；其他可见会话仍会继续采集，已开始的命令正常结束。
- CPU：从 `/proc/stat` 获取累计时间，相邻有效快照计算忙碌比例；首次、计数回退或无有效增量显示未知，不把 load average 当使用百分比。
- 图表：CPU、内存、各 GPU 利用率和显存占用，浏览器内最多 60 个真实点、10 分钟；不重复添加同一快照，不填补离线/隐藏造成的空档，刷新页面后重新积累。后端仍只存最新快照。
- 主题：默认 light，右上角一键切换 dark，主题偏好保存在当前浏览器 localStorage；存储不可用时仍能切换，不新增闲置配置。表格、弹窗、输入框和图表共用主题颜色。
- 验证：全量 72 项测试通过；租约启动兜底调整后另跑 worker 14 项通过。Ruff/格式、两份 JS 语法及 44 个项目文本检查通过；真实浏览器验证默认白天、主题记忆、折线有效值和窄屏。
- 实际服务已正常重启。用现有管理账号在真实 Ordin 机器查看页面，观察到新采样及 CPU/内存/GPU/显存曲线更新，成功切换夜间；离开页面后确认本次租约已删除，未影响其他查看会话。预览截图保存在忽略目录 `runtime/previews/dashboard-light.png` 与 `dashboard-dark.png`。
- 原有机器与台账保持，未创建、停用或删除远端账号；此阶段仅做监控和只读探测。账号回收的实机验收仍见 [Todo](../TODO.md)。
