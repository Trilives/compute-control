# 告警置顶、台账行操作与 root 展示过滤

人类设置目标与验收标准，Agent 在现有页面/业务投影边界内实现。用户要求告警不被弹窗遮挡、三列卡片与统计气泡对齐、移除重复账号清单，并在所有账号展示中过滤 root。

- 错误和告警使用原生顶层 alertdialog，只保留一个“确定”按钮，多个告警排队确认；其他普通弹窗随后打开时仍将当前告警提升到最上层。确认后原弹窗和表单内容保持，错误不自动消失。普通成功状态继续轻量提示，避免每次成功操作都阻塞后续使用。
- 姓名未登记或停用的登录失败响应附管理员姓名、联系方式和旧联系文本，前端直接在告警中显示，便于尚未登录的人联系；不附申请者名单，管理员密码错误不附联系人。
- 统一由 dialogs.js 承担通知显示与层级，保留原 API/表单错误入口；身份退出清空待显示告警，避免前次身份的提示重现。
- 桌面机器区三列等分、18px 间距，与上方三统计气泡外边缘和宽度完全对齐；平板和手机分别两列/一列。
- 重新分配、密码、回收、台账清理、核查结果及清理原 home 等操作归入对应账号表格行，移除下方重复账号/机器文字列表；数据与服务端校验保持。
- 公开机器快照的用户、GPU/活动进程和用户名列表，以及账号台账、归档和权限申请查询过滤 root。原始快照和保护规则保留，仍拒绝申请、接管或删除 root，不因隐藏而修改实际用户。
