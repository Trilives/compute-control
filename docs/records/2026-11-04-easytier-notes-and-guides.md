## 功能和安全边界

- 申请者可删除自己发布的备注，网页管理员可删除任意备注；服务端在同一事务检查稳定作者身份、机器可见性和备注归属，记录审计。没有新增数据库迁移或远端命令。
- 页面仅给有权删除的备注展示按钮，删除需要确认，摘要随之更新，未发布草稿保留；改名不改变备注归属，匿名或缺少 CSRF 的写入被拒绝。
- 账号台账按机器分类，机器下面列出人员、Linux 用户名、状态、sudo 权限和原有行操作。申请者仍仅看到自己的账号，网页管理员用滑动开关切换各账号 sudo 权限，实际结果仍由原后台任务核验。
- Linux 权限统一称“sudo 权限”，避免与网页管理员模式混淆。
- 网页指南通过已认证接口按真实会话角色返回对应 HTML 和 PDF，申请者不能用参数读取管理员版本；文件在受限运行目录，未放公共静态目录或 wheel，响应禁止缓存，退出时清除教程。
- HTML 使用无脚本 sandbox iframe，专用 CSP 仅允许内嵌图片与样式；未安装产物时保留原文字指南回退。
